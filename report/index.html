Models and promotions

Every model version is registered with its exact parameters, so a library upgrade cannot silently change a live model. A promotion rebuilds every card's schedule from the append-only review log.

How to read this

Log loss

The main score. It punishes confident mistakes: saying 95% for a card I then forgot costs far more than saying 60%.

Calibration

The scheduler acts on the probability itself (a card is due when recall would drop below 90%), so a model must be right about the number, not just the ranking.

Bootstrap over cards

Reviews of the same card are not independent. The gate resamples whole cards and asks how often the challenger still wins; one lucky week is not enough.

Why "no promotion" is a result

With a few dozen usable reviews a day, the evidence takes weeks. Until then the champion keeps scheduling; the gate refusing is the system working.
